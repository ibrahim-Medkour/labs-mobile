# 01 — PROJET TECHNIQUE

## Présentation du projet

Notre projet est une plateforme web de films.

Elle permet aux utilisateurs de chercher et de découvrir des films en ligne.

## Les objectifs

- Chercher des films.
- Voir les informations des films.
- Voir les catégories.
- Regarder les films disponibles.
- Gérer les films avec un espace administrateur.

## Les utilisateurs

- **Visiteur :** cherche et découvre les films.
- **Administrateur :** gère les films et les catégories.

<!-- _class: stack -->
# 02 — STACK TECHNIQUE

Notre projet utilise plusieurs technologies pour développer l'application.

## Langages de programmation

- **PHP Native :** développe la logique backend.
- **Kotlin :** langage de programmation.

## Frameworks

- **Laravel :** facilite le développement backend.
- **Tailwind CSS :** facilite le design des pages.
- **Alpine.js :** ajoute des interactions.

## Bibliothèque et base de données

- **Preline :** propose des composants d'interface.
- **MySQL :** stocke les données du projet.

# 03 — COMPRENDRE LES LABS

## C'est quoi un Lab ?

Un Lab est un exercice pratique.

Il permet de découvrir une technologie ou un outil.

## Pourquoi réaliser des Labs ?

- Découvrir de nouveaux outils.
- Apprendre de nouvelles technologies.
- Faire des exercices pratiques.
- Tester des solutions.
- Améliorer nos compétences.

## Quel est le lien avec le projet technique ?

Les Labs nous aident à préparer notre projet.

Nous apprenons et testons les outils avant de les utiliser dans notre application.

**Apprendre → Tester → Réaliser**
